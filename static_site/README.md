## 🚀 Free Static Hosting Options

### 1. GitHub Pages
- Push this folder to a GitHub repository branch (e.g. `gh-pages`) or select `Deploy from /static_site folder`.

### 2. Vercel
- Run `npx vercel static_site` or connect your repo on vercel.com and set **Root Directory** to `static_site`.

### 3. Netlify
- Drag and drop the `static_site/` directory directly into [app.netlify.com/drop](https://app.netlify.com/drop).

### 4. Cloudflare Pages
- Connect repo on Cloudflare Pages dashboard and set build output directory to `static_site`.
